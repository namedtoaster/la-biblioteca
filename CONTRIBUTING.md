# Contributing

Thanks for helping. Two kinds of help matter equally here.

## Questions (no code needed)

Good daily questions are the heart of the app. A good one:

- can be answered in 30 seconds by a beginner, and in 3 minutes by someone fluent
- is about the speaker's own life, so there is no wrong answer
- comes with an English hint and three helper words or phrases

Open an issue with your question, or add it to `lib/questions.ts` in a pull request. Question text is licensed CC BY-SA 4.0.

## Code

1. Fork, then `npm install`.
2. Make your change. Keep it small and focused.
3. Run `npm run check`. It type checks, runs the tests, and fails on long dashes (em or en), which this project does not use anywhere.
4. Open a pull request saying what changed and why.

Before a first pull request is merged, contributors will be asked to agree to a contributor license agreement, so the project can keep its licensing options open. It is being set up.

## Safety and privacy

Never commit recordings, keys, or real user data. Moderation thresholds and blocklists live outside this repository on purpose.
